# Shelfwise

Shelfwise is a small lending service for a community library: members borrow
books, loans have due dates, and overdue loans accrue fines.

This is a **synthetic fixture** for Context Orchestrator. It is realistic
enough to retrieve from, but it is not a working product.

Layout: `docs/` (decisions, conventions, constraints, known issues),
`db/schema.sql`, `src/shelfwise/`, `tests/`.
